## 一、电容是什么

电容器由两个相互绝缘的导体构成，可以在电场中储存能量。其基本关系为：

\[
Q=CV
\]

其中：

- \(Q\)：电荷量，单位为库仑（C）。
- \(C\)：电容量，单位为法拉（F）。
- \(V\)：电容两端电压，单位为伏特（V）。

工程中常见单位：

- \(1\text{ mF}=10^{-3}\text{ F}\)
- \(1\text{ μF}=10^{-6}\text{ F}\)
- \(1\text{ nF}=10^{-9}\text{ F}\)
- \(1\text{ pF}=10^{-12}\text{ F}\)

### 例题

一个 \(100\text{ nF}\) 电容充到 \(3.3\text{ V}\)，储存的电荷为：

\[
Q=CV=100\times10^{-9}\times3.3
\]

\[
Q=330\text{ nC}
\]

电容中储存的能量为：

\[
E=\frac{1}{2}CV^2
\]

代入后：

\[
E=\frac{1}{2}\times100\text{ nF}\times(3.3\text{ V})^2
\approx0.545\text{ μJ}
\]

这个能量很小，但去耦电容距离芯片很近，能够在极短时间内提供瞬态电流。

## 二、电容电压为什么不能突变

电容的电流、电压关系是：

\[
i=C\frac{dv}{dt}
\]

整理得到：

\[
\frac{dv}{dt}=\frac{i}{C}
\]

如果电容电压要在零时间内发生有限变化，那么 \(\frac{dv}{dt}\) 将趋于无穷大，需要无穷大的电流。真实电路无法提供无穷大电流，所以电容电压不能瞬间跳变。

但要注意：

- 电容电压不能突变。
- 电容电流可以突然改变。
- 电阻两端电压可以随电流快速变化。
- 理想模型与真实器件仍有差异，真实电容还包含 ESR、ESL 和漏电。

### 手算例题

一个 \(1\text{ μF}\) 电容由恒定 \(1\text{ mA}\) 电流充电，电压上升速度为：

\[
\frac{dv}{dt}=\frac{1\text{ mA}}{1\text{ μF}}
=1000\text{ V/s}
\]

换算为更直观的单位：

\[
1000\text{ V/s}=1\text{ V/ms}
\]

因此理想情况下，电压从 0 V 上升到 3 V 需要约 3 ms。

## 三、RC 充电过程

当电阻 \(R\) 与电容 \(C\) 串联接到电源时，电容不会瞬间达到电源电压。

充电公式：

\[
V_C(t)=V_{DD}\left(1-e^{-t/RC}\right)
\]

时间常数：

\[
\tau=RC
\]

在不同时间点，电容电压大约为：

| 时间 | 充电电压占最终值 |
|---:|---:|
| \(1\tau\) | 63.2% |
| \(2\tau\) | 86.5% |
| \(3\tau\) | 95.0% |
| \(4\tau\) | 98.2% |
| \(5\tau\) | 99.3% |

工程上常把 \(5\tau\) 看作“基本充满”，但数字输入什么时候识别为高电平，应看它跨过 \(V_{IH}\) 的时刻，而不是等到 100%。

### 例题

\[
R=10\text{ kΩ},\qquad C=100\text{ nF}
\]

时间常数：

\[
\tau=RC=10\,000\times100\times10^{-9}=1\text{ ms}
\]

若电源为 3.3 V：

- 1 ms 后约为 \(3.3\times63.2\%=2.09\text{ V}\)
- 3 ms 后约为 \(3.3\times95.0\%=3.14\text{ V}\)
- 5 ms 后约为 \(3.3\times99.3\%=3.28\text{ V}\)

如果输入的 \(V_{IH}=0.7V_{DD}=2.31\text{ V}\)，跨过高电平阈值的时间为：

\[
t=-RC\ln\left(1-\frac{V_{IH}}{V_{DD}}\right)
\]

\[
t=-1\text{ ms}\times\ln(0.3)\approx1.20\text{ ms}
\]

所以这个输入大约在 1.20 ms 后才被可靠识别为高电平。

---

## 四、RC 放电过程

已充电电容通过电阻放电时：

\[
V_C(t)=V_0e^{-t/RC}
\]

其中 \(V_0\) 是放电开始时的电压。

| 时间 | 剩余电压占初始值 |
|---:|---:|
| \(1\tau\) | 36.8% |
| \(2\tau\) | 13.5% |
| \(3\tau\) | 5.0% |
| \(5\tau\) | 0.7% |

如果数字输入的 \(V_{IL}=0.3V_{DD}\)，从 \(V_{DD}\) 放电到低电平阈值所需时间：

\[
t=-RC\ln(0.3)\approx1.20RC
\]

这个结果与充电跨过 \(0.7V_{DD}\) 的时间相同。

## 五、上拉电阻为什么会减慢上升沿

开漏输出主动拉低时，晶体管提供低阻通路，下降沿通常较快；释放总线后，只能依靠上拉电阻给总线电容充电，因此上升沿是 RC 曲线。

总线电容可能来自：

- MCU、FPGA 和传感器的输入电容
- PCB 走线
- 连接器和排线
- 示波器或逻辑分析仪探头

对于一阶 RC，上升时间常用 10% 到 90% 定义：

\[
t_r\approx2.2RC
\]

### 例题：I²C 上拉

假设：

\[
R_P=4.7\text{ kΩ},\qquad C_{BUS}=100\text{ pF}
\]

\[
t_r\approx2.2\times4.7\text{ kΩ}\times100\text{ pF}
\]

\[
t_r\approx1.03\text{ μs}
\]

如果减小为 \(2.2\text{ kΩ}\)：

\[
t_r\approx484\text{ ns}
\]

上拉电阻越小，上升越快，但输出拉低时的灌电流越大：

\[
I_{LOW}\approx\frac{V_{DD}-V_{OL}}{R_P}
\]

因此上拉电阻不是越小越好，需要同时满足：

1. 上升时间要求。
2. 输出低电平时的灌电流能力。
3. \(V_{OL}\) 仍低于接收端的 \(V_{IL}\)。
4. 总功耗可以接受。

## 六、数字边沿与输入不确定区

数字输入在 \(V_{IL}\) 与 \(V_{IH}\) 之间时，不能保证识别为 0 或 1。慢边沿会让信号在这个区域停留更久，可能带来：

- 翻转时刻不确定。
- 更容易受噪声影响。
- 某些 CMOS 输入产生额外的贯通电流。
- 同一信号到达多个输入时产生不同判断。
- 时钟输入出现严重问题，甚至重复触发。

普通数字输入与施密特触发输入不同：

- 普通输入通常只有规定的高、低阈值范围。
- 施密特触发输入具有迟滞，输入上升和下降时的翻转阈值不同，更适合慢边沿或有噪声的信号。

不能因为输入带施密特触发就无限放慢边沿，仍应遵守数据手册中的输入上升、下降时间要求。

## 七、去耦电容为什么靠近芯片

FPGA 或 MCU 内部大量晶体管在时钟边沿附近同时翻转，会产生短促的电流需求。电源走线、过孔和封装引脚都具有寄生电感，远处电源无法瞬间提供这部分电流。

去耦电容的作用是：

1. 在芯片附近提供瞬态电流。
2. 减小局部电源电压跌落。
3. 为高频电流提供较短的回流路径。
4. 降低电源噪声向其他电路传播。

常见的 \(100\text{ nF}\) 只是经验起点，具体数量、容值、封装和布局必须参考芯片数据手册、硬件设计指南和参考设计。

关键布局原则：

- 靠近对应电源引脚。
- 电容到电源脚、地的环路尽量小。
- 避免细长走线和不必要的过孔。
- 不要只看原理图连接正确，还要看 PCB 电流路径。

## 八、按键 RC 滤波的边界

机械按键按下和释放时会发生抖动，信号可能在数毫秒内多次跳变。RC 电路可以减缓这些变化，但它也会形成慢边沿。

一种典型思路是：

```text
3.3 V
  |
 上拉电阻
  |
  +------> MCU/FPGA 输入
  |
 电容
  |
 GND
```

但仅靠 RC 不一定足够：

- 输入最好具有施密特触发特性。
- FPGA 中还需要考虑异步输入同步。
- 后续通常仍需数字消抖。
- RC 参数过大可能导致输入边沿过慢。

“滤波”“同步”和“消抖”解决的不是同一个问题：

- RC 滤波：抑制部分高频变化。
- 同步器：降低异步输入引起亚稳态传播的概率。
- 数字消抖：确认状态持续稳定一定时间后才接受变化。

亚稳态和数字消抖将在后续课程展开。

## 九、与 STM32L432 和 FPGA 的联系

### STM32L432

查看数据手册时，可以搜索：

- `I/O static characteristics`
- `Input leakage current`
- `Input capacitance`
- `NRST characteristics`
- `External clock characteristics`
- `I2C characteristics`

这些参数帮助你判断输入负载、允许边沿速度、复位 RC 网络和 I²C 上拉设计。

### FPGA

FPGA 每个 I/O Bank 的电压和 I/O Standard 必须正确配置。线路电容、驱动强度和 Slew Rate（转换速率）会共同影响边沿：

- 驱动过弱：边沿可能太慢。
- 驱动过强：可能增加过冲、振铃、串扰和电磁干扰。
- 目标不是“越快越好”，而是满足时序并保持足够信号完整性。

## 十一、实践任务

使用 STM32L432 数据手册或你的开发板原理图完成以下记录：

1. 找到一个 GPIO 的输入电容参数；如果数据手册没有给出单引脚典型值，明确记录“未找到”，不要猜测。
2. 找到 `NRST` 引脚外围电路，记录是否连接电容以及电容值。
3. 找到开发板上至少一个 \(100\text{ nF}\) 去耦电容，并确认它连接到哪组电源。
4. 找到 I²C 引脚，确认开发板是否自带上拉；若有，记录上拉电压和阻值。
5. 用文字画出一次数字信号路径：

```text
输出驱动器 → PCB走线/连接器 → 输入引脚
```

在每一段旁标注可能产生的电阻、电容或电感影响。

如果没有开发板原理图，只完成数据手册查阅部分即可，不要根据外观推测连接关系。

## 今日核心结论

数字信号虽然最终被解释为 0 和 1，但实际传输的是连续变化的电压和电流。电阻、电容、线路和输入负载共同决定边沿何时跨过逻辑阈值。理解 RC 暂态，是理解 I²C 上拉、按键、复位、去耦、时钟质量和信号完整性的共同起点。
